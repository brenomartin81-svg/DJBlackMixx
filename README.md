# DJBlackMix (v0.5)

Aplicativo de DJ para Android com dois decks independentes, controle de Pitch, Cue, volumes individuais e Crossfader Equal-Power.

## Como gerar o APK pelo GitHub:
1. Suba todos os arquivos deste repositório para o GitHub.
2. Acesse a aba **Actions** no seu repositório.
3. Aguarde a conclusão do fluxo **Gerar APK DJBlackMix**.
4. Clique na execução concluída e baixe o artefato **DJBlackMix-APK** na seção *Artifacts*.
